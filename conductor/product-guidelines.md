# Product Guidelines - Elysia SQLite Admin

## Tone and Voice
- **Professional & Efficient:** Communication is direct, clear, and prioritizes speed and task completion.
- **Helpful & Instructive:** Provides clear context and guidance for complex database operations.
- **Friendly & Approachable:** Maintains a respectful and welcoming tone to ensure a smooth user experience.

## Design Principles
- **Clarity over Density:** Prioritizes legibility and intentional use of whitespace over maximum information density.
- **Visual Aesthetic:** Clean and minimalist, inspired by modern productivity tools (Notion, Linear), emphasizing typography and subtle UI elements.
- **Standardized Components:** A consistent set of UI elements (buttons, inputs, modals) creates a predictable and reliable environment.
- **Responsive Design:** Optimized for desktop use while remaining fully functional on tablets and varying screen sizes.

## Interaction Patterns
- **Safety First:** Explicit confirmations are required for all destructive database actions (e.g., deletions, schema changes).
- **Optimistic UI:** Updates the interface immediately for a snappy feel, with clear background state synchronization.
- **Progressive Disclosure:** Advanced settings and complex configurations are hidden by default to keep the primary interface focused.
